# Reusable design grammar

These are recommended defaults synthesized from inspected editorial and product references, not exact measured specifications.

- Content-native surfaces: group with alignment, spacing and tone before adding containers. A task list is usually rows, not tiles.
- Quiet shell, expressive content: navigation remains predictable while the selected work receives attention.
- Deliberate typography: regular-weight headings, readable prose, compact technical labels only where useful. Use tabular numerals for comparisons.
- Restrained accent: reserve emphasis for selected context and meaningful actions. Status has its own semantic vocabulary.
- Pane relationships: persistent context beside active work, with evidence/details available without losing the current task. Keep composer visible; an inspector must not cover it. Aim for comfortable conversation line lengths, roughly 60–75 characters, then inspect actual text.
- Editorial rhythm: large statements and media can introduce a public product; compact repeated tasks need a different density.
- Softness without blur: adjacent tonal surfaces, gentle corners and fewer boundaries; keep focus and required control edges clear.

The references were desktop captures. Responsive behavior, exact spacing, typography values, keyboard interactions and motion recommendations are design judgments, not facts proven by those captures. Consent banners and partially revealed sections are capture artifacts, not visual patterns to reproduce.

Claude contributed a reference review through an external design CLI. Recommendations were edited for portability, accessibility and honest tool limits. Private source captures and source identity are intentionally not distributed with this suite.
