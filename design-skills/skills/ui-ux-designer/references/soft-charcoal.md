# Optional project profile: soft charcoal operations

Apply only when the project asks for this direction. This profile uses compact operating layouts, no emoji, text navigation, workspace → project → Conversation / Progress / Reviews, model/effort selectors with explicit scope and clickable run details. Keep all supplied requirements when refining the UI.

Use warm charcoal canvas #1E1D1B, sunken #191816, raised #262523 and overlay #2E2C29. Primary text #ECE8E1, secondary #B5AFA5, muted #948E84. Muted text is allowed on canvas/raised only; it fails ordinary-text contrast on overlay. Use secondary there. A quiet decorative seam #34322E is not an accessible interactive boundary. Use #8B857C where an essential boundary must be visible. Focus #C9A86A. Primary action fill #D9D3C7 with canvas-colored text. Semantic success #8DBF8B, danger #E08A7A, warning #D9B060 and info #8FB3D9.

The companion tokens.json enumerates supported text/surface pairs; recompute after changes. Do not assume every possible pairing passes.

Start with 14 px reading text, 12–13 px metadata, 14 px medium pane titles, 18–22 px page titles. Use 400/500 weights, system sans and a system monospace for technical output. Spacing 4/8/12/16/24/32 px. Default rows 32–36 px, compact 28 px only when targets remain usable. Controls 6 px radius, popovers 8 px, grouped panels 10 px. These are adjustable defaults, not source measurements.

Use subtle tonal elevation; overlays may cast a restrained shadow. Keep focus clear. No scroll reveals in the workspace. Short feedback transitions honor reduced motion. Do not apply this profile to unrelated products without a reason.
